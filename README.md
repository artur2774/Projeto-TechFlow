# TechFlow Dashboard

Projeto desenvolvido para o Checkpoint 5 de FrontEnd Design.

Dashboard responsivo da empresa fictícia TechFlow para acompanhar
projetos, equipes e indicadores.

## Integrantes

- Artur de Novazzi Maia — RM: 572624
- Bruno Araujo Castro — RM: 572723

## Tecnologias utilizadas

- HTML5
- Tailwind CSS 4
- JavaScript puro
- Vite
- npm

## Principais recursos implementados

- Layout responsivo com abordagem Mobile-First.
- Navbar e sidebar com menu mobile.
- Quatro indicadores.
- Seis cards iniciais com CSS Grid e tamanhos diferentes.
- Cadastro de projetos em modal.
- Validação visual com estados de erro e sucesso.
- Inclusão de novos projetos na interface.
- Pesquisa de projetos.
- Dropdown do usuário.
- Temas Claro, Escuro e Sistema.
- Preferência de tema armazenada no localStorage.
- Estados hover, focus, active, disabled e group-hover.
- Transições e microinterações.

Os projetos cadastrados ficam na memória da página e são removidos
ao recarregar. A preferência de tema permanece salva.

## Como executar

É necessário ter Node.js e npm instalados.

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Abra o endereço informado no terminal.

Para gerar a versão de produção:

```bash
npm run build
```

Para visualizar a versão de produção localmente:

```bash
npm run preview
```
